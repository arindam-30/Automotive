This repository contains MATLAB and Simulink implementations of a lateral vehicle dynamics model, capturing the coupled lateral and yaw motion of the vehicle.

The model is developed to simulate standard handling manoeuvres such as step steer, sine dwell, and constant-radius cornering, enabling analysis of transient and steady-state response. Tire forces are modeled to represent lateral force generation as a function of slip angle, allowing evaluation of key metrics including yaw rate gain, sideslip angle, and vehicle stability characteristics.

The framework can be used to study the influence of vehicle parameters such as mass distribution, cornering stiffness, and steering input on overall handling performance.

To run, use the main_lateral.m file.
