This repository contains MATLAB and Simulink implementations of a 3-DOF longitudinal vehicle dynamics model, incorporating vehicle body motion, wheel rotational dynamics, and drivetrain interactions.

The model is designed to simulate straight-line vehicle performance under various operating conditions, including acceleration and traction-limited scenarios. It supports evaluation of powertrain behavior and enables systematic optimization of gear ratios to improve performance metrics such as acceleration and efficiency, given engine maps and vehicle parameters.
